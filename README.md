
# 🍔 Flutter Foodie App

A modern food delivery app UI built with Flutter and Dart, recreated from a Figma design. It features a clean dark theme, attractive food cards, onboarding screens, and a detailed food product page.

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- Android emulator or physical device

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/hamza-hafeez-dev/flutter-foodie-app.git
   ```

2. Navigate to the project directory:

   ```bash
   cd flutter-foodie-app
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the app:

   ```bash
   flutter run
   ```
